# TimescaleDB / Tiger Data

TimescaleDB is the open-source PostgreSQL extension for time-series data built by Timescale (now Tiger Data). It is a product, not a separate API provider: the Tiger Cloud REST APIs and the PostgreSQL wire interface are profiled in the timescale repository, which is canonical. Consolidated 2026-10-13, approved by Kin Lane.

Canonical profile: [api-evangelist/timescale](https://github.com/api-evangelist/timescale) — https://apis.io/providers/timescale/
